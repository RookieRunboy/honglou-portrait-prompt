# 语料检索指南

## 定位资料

优先使用用户指定的资料目录；其次检查当前项目或父目录是否同时包含 `sources/` 与 `foreshadowing/`。若本地语料位于其他目录，使用用户提供并已确认存在的实际路径；不假定作者电脑上的目录结构。

技能目录与语料目录是两回事：安装在 `~/.codex/skills/` 后，不要从技能目录错误推导语料的相对位置。

若找不到本地语料：在可联网时检索可直接阅读的原文，例如维基文库《脂硯齋重評石頭記》及分回页面；打开原文核实，不仅凭搜索摘要或人物百科。记录实际版本和链接。若本地与联网都不可用，不冒称已经查证；只有在本轮上下文已有足够原文时才能据此完成，否则简短说明缺少可核对的材料，请用户提供文本或路径。若用户明确允许凭已知内容自由创作，则标明未经本次核验，避免伪造逐字引文。

## 最短检索路径

1. 读取对应 `foreshadowing/by-character/<slug>.md`，寻找有关回目、引文和条目 ID。
2. 在 `sources/zhiping/wikisource_huiji/text/NNN.txt` 读取引文上下文，核对主语、事件和意象。不要从短句脱离上下文推断动作归属。
3. 若要引用脂批，在该版本 `comments.jsonl` 找到原记录，检查 `chapter`、`anchor`、`text`、`witnesses`、`label_raw`；汇集本中的批语来自不同本子。
4. 对尚未覆盖的外貌或代表情节，用 `rg -n -C` 在该版本的 `text/` 中查找姓名、别称或关键词，再读取相关段落。不必载入全书。
5. 涉及版本差异时，查对应版本的正文与 `manifest.json`；不把不同版本的读法拼成一句“原文”。

示例（在已确认的语料库根目录执行）：

```sh
rg -n -C 3 '俊眼修眉|軟翅子大鳳凰|清明涕送' sources/zhiping/wikisource_huiji/text/
rg -n '此探春遠適' sources/zhiping/wikisource_huiji/comments.jsonl
```

`text/` 保留字词与标点，可用于引文；`norm/` 是繁简、异体字归一后的比对层，不作为原文引用来源。行号可能随数据重建变化，引用前重新核对。输出本地来源时使用实际绝对文件路径和单一起始行号。

## 本库的资料性质

- 默认 `sources/zhiping/wikisource_huiji/`：80 回脂评汇集本，以庚辰为主，非纯庚辰。不能将其全部正文或批语标为庚辰原文。
- `sources/zhiping/jiaxu/`：甲戌本所存 16 回。只在实际存在的回目中查证，不用它作为全书已有的假设。
- `sources/chenggao/chengjia/`：120 回程甲本录文，可核查该版本续书情节，仍有未校对页面。
- `sources/chenggao/chengyi_working/`：自动合成的程乙工作本，未经人工通校；不以其单个可疑字裁决原文。
- `sources/guiyou/zj2009/`：108 回第三方癸酉录文；仓库按现代争议文本收录。仅在用户指定或比较相关写法时使用，不作为曹雪芹原意的既定证据。
- 人物伏笔页与 `foreshadowing/foreshadowing.jsonl` 有人工/模型解释；“通行解读”“推测”“置信度高”仍不是正文。对具体结局尤须回查。

如采用有争议的意象，可选择更稳妥的字面图像，或明确其解释性质；例如只画判词所见图像，不据此断言具体婚配或死法。
