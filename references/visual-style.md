# 系列视觉规范

这些是未另行指定时的默认设计。用户选择具体场景、时代造型、媒介、比例或文字策略时，应整体协调，而非将默认要求继续叠加造成冲突。

## 系列默认语言

- **画幅与层级**：竖版 4:5，一位人物为视觉中心，默认疏朗构图。先确定成片留白的形状与位置，再决定人物占比；人物可偏左，但不默认贴满画高。需要题字时可在主要空处安排竖排文字，不把固定空白栏当作全部留白。
- **绘画方法**：借鉴宋元人物画的细劲工笔线描与层层设色；低饱和矿物色薄染，重要局部可重彩。色彩饱和度与明暗对比分开决定：统一的灰青、米白中也可保留清楚的黑发、深色器物和亮部。
- **材质与排版感**：温润、细微的宣纸纹理，人物刻画清晰；按空间关系安排远景虚实。纸纹不能遮盖脸、眼睛和细小器物，纸感不能成为全画泛白的理由。
- **梦境气氛**：以云气、空间虚化、册页边缘或隐约框景暗示太虚幻境、薄命司。每张选一种合适方式即可，不必把宫殿、册页、烟云和符号全部实体化。
- **服饰气质**：默认清代文学语境中的人物身份。依据场景选择裙袄、发式、配饰，不把“清代仕女”自动变成后妃大旗头。若无实物服饰考据，表述为美术演绎，不声称精确复原。

## 先决定全画关系，再安排物件

按主文件完成构图选择后，用下列维度落实设计。按场景需要采用，完整提示词只写影响成图的决定，不机械填满六项：

| 决策 | 可画出的关系 |
|---|---|
| 留白与占比 | 主要空处在哪里、怎样连成片，与人物视线或动作有什么关系；据此确定人物尺度，按需裁切，不默认近景满幅 |
| 视点与取景 | 从正面、侧面或侧后方看；视线高度；哪些环境片段足以交代场景，哪些区域可以不画 |
| 人物动态 | 肩背、头部、视线各朝哪里；重心与手的落点；身体是否因动作产生转折。静坐也可以有明确的姿态关系 |
| 主方向 | 选择最能组织此画的垂直、水平、斜向或弧线关系，使人物轮廓、环境边缘或运动方向相互呼应；不强制使用对角线 |
| 空间层次 | 用必要的接触、遮挡或尺度差建立空间；距离也可由两笔远景之间的大块空白表现，不必逐层铺满近中远景 |
| 明暗与疏密 | 定出面部、手或关键动作的焦点，以及深色支点、亮部和安静区域；通常二至三种主色配少量点色，避免所有区域同样浅、同样细 |
| 留白边界 | 指明画面如何进入空处，哪些轮廓保持清楚、哪些远景逐渐隐去；与人物朝向、视线和文字位置协调 |

“物件在左上、人物在左边”只完成定位。还要检查它们是否在比例、方向或明暗上形成联系，而不是各自占一个角落。

人物外貌优先采用可查描写，不以网红脸替代辨识度。动态服务于年龄、身份与情节，不把所有人物改成回眸、飘衣或低头流泪。巧姐幼时与判词中的成年图像不能无说明地混为一个实景；欢乐名场面也不因系列主题是“薄命”就被改写为悲剧结局。

## 叙事意象与画面细节分工

- **核心叙事意象**：选少量已查证、与主题直接相关的意象，不必凑齐数量，控制它们之间的竞争。跨回材料可置于梦境层，不制造它们真实同时发生的误解；真实物件与谐音隐喻也须区分。
- **空间细节**：帘幕、船帆、栏杆、树影或室内陈设，可以用于框景、透视、尺度与遮挡。这些是可选手段，不是应逐项补全的清单；一段栏杆或一角帘幕足以成立时，不再扩建完整环境。
- **身份与材质细节**：衣缘纹样、发饰、织物褶皱等可表达身份、动作和触感。是否繁简取决于人物与场景，不能把“性格坚定”自动翻译成素衣素簪。

每项细节应有作用，但个别有用不代表合在一起都该保留。默认细节聚集在面部、手部、少量衣饰或关键动作附近，外围逐渐简省；不要同时要求满衣锦纹、满幅浪花、成排楼阁与密集云层。删掉次要内容后主题仍清楚，就优先删减，保留局部的精致与明暗。

不将探春的船帆、斜栏、金纹与凤凰固定为全系列模板；每个人物都要重新选择这些功能由什么来承担。构图和配色属于设计选择，不冒称原书的规定。

## 留白先于景物铺陈

先安排主要空处，以及人物周围必要的间隙，再放置实体。留白可作为未画出的天空、水面、庭院、墙面或纯纸面，由少量边界让观者补足；不必用密集云气、波纹或花瓣来证明这些空间存在。空处应能连成片，不能被装饰切成零碎缝隙。

默认追求“局部精、整体疏”，不以固定百分比替代判断。正面肖像、近景或繁密场景如为用户明确要求，可调整空处的尺度与形式；仍检查实处与空处是否互相衬托。

采用有机过渡时，写清哪些环境边缘渐淡，人物五官、手与关键动作保持清楚；也可以用截断的枝条、局部器物和清楚纸面直接形成虚实。浅色细节遍布全画仍然拥挤，不能用整体降低透明度代替留白。

题字区只是留白的一种用途。需要文字时，从已有空处选出连续、浅色、可读的区域；没有题字也保留服务于距离、安静或视线延伸的空处。用户明确不要留白时服从其要求，重新分配空间。

## 提示词应可直接画出

较弱：人物孤独、清雅，背景精致，右侧留白。

较强：人物缩置于画面左下，窗框的竖线与微垂的颈线呼应；面部和持物的手保持清楚，空室向右展开，浅色墙面承接文字区。

此例只说明如何描述人物尺度、线条、焦点与空处的关系，不规定人物都要低头坐在窗边。性格词应有这些视觉关系支撑，不能仅靠“聪敏、坚定、清雅”让模型自行猜姿态。

物件名称容易产生歧义时写明形态：凤凰“风筝”是竹骨纸翼，不是活凤凰；册页是纸面与页缘，不是现代精装书堆。实体大小、数量与视角服从画面主次。

完成后把画面想象成缩小的黑白草图：主要空处是否一眼可见，人物轮廓是否清楚，细节是否集中，视线能否朝空处舒展？若每个角落都有东西，优先删掉次要背景或缩小其占地；若只剩孤立符号，先调整它们与空处的关系，不靠增加物件补救。

## 文字与避免项

默认画内不生成文字。留白首先服务构图，也可供后期排版；另给人物名和一行短题字，可以选核实的判词，也可以自拟并标明。

用户要求文字入画时，明确逐字内容、竖排阅读顺序、文字区位置与字号层级，不再写“无文字”。用户要求无字成图且不需要题字时，不附题字建议。

避免项只针对本张图的实际歧义，合并在提示词末尾或按用户指定模型的格式提供。例如探春避免“真人凤凰、皇后凤冠、通篇婚庆红”；不要附加与人物无关的长串通用负面词。

没有指定模型时，输出自然中文，不擅自添加 `--ar`、`--stylize`、采样器、权重括号等专用语法。若指定模型且当前语法无法确认，先查官方资料；画面语义保持可迁移。
